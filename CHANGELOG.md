# Changelog / История версий

## 0.2.0 — beta (2026-10-06)

Первый публичный выпуск. / First public release.

- Сканер служб Windows с описаниями на русском: что делает служба, что будет при отключении, уровень риска.
  Защищённый список из 41 системной службы, которые WinLite никогда не меняет.
- «Быстрая чистка»: готовые сценарии (трекеры, реклама, службы для отсутствующего железа, сетевая безопасность, автозагрузка и др.).
- «Приватность»: 16 настроек реестра для рекламы и телеметрии с описанием последствий.
- «Автозагрузка»: список программ с иконками, включение и отключение так же, как в Диспетчере задач (ничего не удаляется).
- Резервные копии: перед каждым применением сохраняется прежнее состояние, откат одной кнопкой.
  Точка восстановления Windows создаётся с проверкой: если Windows её пропустила (лимит «одна в сутки»), WinLite честно об этом сообщает.
- Кнопка «Найти в интернете» для служб и программ, которых нет в базе (поиск Google, открывается в браузере по клику).
- Боковое меню, индекс оптимизации, окно «О программе» со сведениями для отчёта об ошибке (копируются вручную, ничего не отправляется).
- Без телеметрии и сетевых запросов.
